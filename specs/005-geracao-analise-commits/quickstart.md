# Quickstart: Geração de Análise de Commits

1. Garantir token configurado nas configurações globais
2. Selecionar projeto e repositório
3. Buscar branches no GitHub e adicionar ao repositório
4. Selecionar branch e período (sprint ou manual)
5. Disparar análise
6. Acompanhar status até conclusão
7. Validar commits importados e associação de aluno quando aplicável
8. Repetir execução com mesmos parâmetros e confirmar histórico preservado
